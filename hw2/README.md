## Get Started

Install necessary packages, such as `numpy`, `pandas`, `librosa`,
`parselmouth-praat`, `scikit-learn`, `scipy`, `seaborn`, `matplotlib`, and `tqdm`.

Place the data under `hw2_data/` (not tracked in git), then run the notebooks in
order: `problem1.ipynb`, `problem2.ipynb`, then `problem3.ipynb`.
